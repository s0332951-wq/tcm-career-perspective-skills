# 中医学博士职业圆桌

## 目标

把抽象的职业标签改写成可以核验的机会包，让五个视角在同一事实基础上独立回答，再形成带条件、否决线、退出机制和下一步实验的决策备忘录。

本 Skill 是协调器，不是第六位人物，也不以多数票替代用户的价值权重。

## 必须遵守的边界

1. 先区分已知事实、对方口头表示、合理推断和未知项。
2. 不假设名校、三甲、高校或“大平台”自动等于可用资源。
3. 不用人物风格回答事实问题。合同、签证、执业、基金、薪酬和招聘制度必须另查。
4. 不伪造人物原话，不声称人物会对用户本人作出确定选择。
5. 每个视角先独立判断，综合阶段才允许互相比较。
6. 用户信息不足时给出条件式分支和最少必要追问，不强行排名。五个席位可以各自标记缺口，但圆桌必须去重并按“最可能反转结论”排序，对用户一次最多提出5个问题。
7. 医学相关输出只讨论职业结构，不给患者诊疗建议。

## 工作流

### 第一步：建立统一事实卡

对每个选项记录：

- 机构、部门、岗位性质、期限和法律身份；
- 直接导师、日常指导者、团队成员及其真实时间投入；
- 已明确的课题、用户负责的工作包、首个六个月任务；
- 经费来源、薪酬或自筹成本，以及资源是否获准使用；
- 数据、样本、设备、伦理、统计和协作接口；
- 署名原则、数据和知识产权、离组后可带走的资产；
- 临床准入、每周患者接触、病例随访和技能复训安排；
- 教学、行政、值班及隐性服务负担；
- 考核、续聘、晋升、留任、退出和失败兜底；
- 两年后能够由本人控制的论文、基金、方法、队列、课程、网络和声誉。

每项已知事实同时记录来源、日期和确认主体。把用户明确声明的临床最低要求、健康底线、个人时间和不可承受损失标为硬约束；硬约束不得被总分补偿。

把“顶尖平台”“资源很多”“支持申请基金”等表述标为待核验，不直接算作事实。完整门槛见 [decision-gates.md](references/decision-gates.md)。

### 第二步：识别可能反转结论的缺口

只追问会改变路径排序的问题。优先询问：

- 这是正式岗位、获批 fellowship、访问身份，还是尚未定义的安排？
- 谁对课题、经费、作者顺序、数据和指导时间拥有决定权？
- 用户是否拥有可辨认的核心问题和可独立带走的成果？
- 临床连续性是真实患者责任，还是仅保留资格证和偶尔观摩？
- 最坏情况下损失什么，何时能退出，退出后回到哪条路？

涉及 PI 时使用 [pi-due-diligence.md](references/pi-due-diligence.md)。

### 第三步：五个视角独立评议

圆桌被用户触发，即构成对以下五个席位的明确委派。先读取精简的 [五视角路由图](references/lens-map.md)，再按当前选项的关键冲突依次读取人物 Skill 中相关章节；不要无差别把五份全文同时塞入上下文，也不依赖它们再次被用户逐个点名：

- [王琦视角](../wang-qi-perspective/SKILL.md)
- [黄璐琦视角](../huang-luqi-perspective/SKILL.md)
- [张伯礼视角](../zhang-boli-perspective/SKILL.md)
- [William Osler视角](../william-osler-perspective/SKILL.md)
- [Richard Hamming视角](../richard-hamming-perspective/SKILL.md)

若某个 Skill 未安装或文件不可访问，明确标注该席位缺席，不凭印象补写。复杂或高代价决策可逐席深读完整正文；每读完一席先压缩成统一模板备忘录，再进入下一席。

每个视角都必须用同一模板：

1. 本视角最看重的目标；
2. 对每个选项的最强支持理由；
3. 最强反对理由；
4. 一票否决条件；
5. 最多三项可能反转本席判断的事实缺口，供圆桌统一去重；
6. 当前条件式建议；
7. 证据标签：直接证据、框架迁移、合理推断或证据不足。

五个视角的职责：

- 王琦：临床差异能否凝练为长期问题、概念工具和个人学术体系；
- 黄璐琦：战略价值、资源可达性、现代科学转译、协作组织与青年独立性；
- 张伯礼：临床价值、内功训练、守正创新、证据校正、任务闭环和平台建设；
- William Osler：真实患者接触、床旁判断、随访、医生身份和临床科研教学循环；
- Richard Hamming：问题重要性、可攻性、优秀同行密度、问题所有权和长期复利。

### 第四步：综合而不抹平分歧

依次生成：

1. **事实门槛结果**：不合规、违反用户硬约束或不可执行的选项先移出排名；信息不足的选项进入“待尽调”，不得等同于失败。
2. **共识**：至少四个视角基于不同理由得出相同结论的部分。
3. **关键分歧**：说明分歧来自目标函数、证据不足还是风险偏好。
4. **否决线**：法律、身份、健康、毁灭性损失及用户硬约束属于全局否决；单个人物视角的“一票否决”只作为强烈警报，除非它命中全局否决或被用户采纳为硬约束，否则不能单独淘汰选项。
5. **条件式排序**：使用“若 A、B、C 均成立，则 X 优先；若 D 不成立，则转向 Y”。
6. **可逆实验**：在签长期承诺前，用访谈、书面确认、短期合作、数据试跑或团队背调减少不确定性。
7. **退出机制**：写明复盘日期、触发器、停止条件和备用路径。

不得只给总分。若使用评分表，必须同时保留门槛项、原始事实和分歧说明。

### 第五步：输出可执行备忘录

默认输出结构：

1. 决策问题与用户权重；
2. 已知事实、未知项和需要外部核验的事项；
3. 各选项门槛表；
4. 五个独立视角摘要；
5. 共识与关键分歧；
6. 条件式首选、备选和否决条件；
7. 下一轮需要向 PI、科室或人事索取的书面信息；
8. 未来 14 至 30 天行动顺序；
9. 下次圆桌应在什么新证据出现后重开。

面向用户的追问清单必须合并同义项，最多保留5项；其余缺口写入尽调清单，不要求用户当场逐项回答。

## 质量自检

回答前检查：

- 是否比较了具体机会包，而不是机构名气？
- 是否把政策事实与人物视角分开？
- 是否说明哪些观点只是框架迁移？
- 是否真实保留临床连续性，而非只保留“临床”标签？
- 是否检查两年后由用户控制的资产？
- 是否写出最坏情况、退出点和备选路径？
- 是否保留了人物间真正的分歧？
- 是否给出下一步可验证动作，而非只给情绪性结论？
