# PI And Team Due Diligence

## 课题与前六个月

1. 我进入团队后负责的具体研究问题是什么？
2. 前 30、90 和 180 天分别要交付什么？
3. 哪些结果是探索性，哪些结果已有初步数据支持？
4. 课题失败时有哪些可转向的问题或数据？
5. 谁负责每日指导，PI 本人多久进行一次一对一讨论？

## 经费与资源

1. 支持该课题的经费来自哪里，覆盖到何时？
2. 身份、薪酬、保险、签证和研究成本分别由谁承担？
3. 设备、数据、样本、伦理和统计支持是否已经批准？
4. 哪些关键资源依赖外部合作者，是否已有书面协议？
5. 若经费中断，岗位和课题如何处理？

## 作者、数据与独立性

1. 作者顺序按什么规则决定，能否用具体旧项目举例？
2. 我是否拥有清晰的第一作者或共同通讯作者路径？
3. 离组后能否继续分析、发表或带走某些数据和方法？
4. 我能否提出并发展相邻的独立问题？
5. 团队如何处理项目重叠、抢题、负结果和贡献争议？

## 训练与职业发展

1. 这段经历最独特、最可迁移的训练是什么？
2. 过去五名相似背景成员去了哪里？
3. PI 如何支持基金申请、论文写作、会议展示和外部合作？
4. 团队成员能否与院内外优秀同行稳定交流？
5. 两年后我应拥有哪三项可以独立证明的职业资产？

## 临床连续性

1. 该安排是否允许并支持合法、持续的临床接触？
2. 若当地不能执业，如何保留病例复盘、随访、短期回国临床或复训？
3. 临床安排是否与实验、签证、机构政策和保险冲突？
4. 谁能确认这些安排，而不只是 PI 口头同意？

## 团队背调

分别询问在组、已离组和合作过的人：

- PI 是否按约定提供时间、资源和作者位置；
- 失败项目如何处理；
- 平均工作时长与隐性值班；
- 团队冲突、人员流动和心理安全；
- 论文从数据完成到投稿的真实周期；
- 成员离组后是否仍能完成论文和获得推荐。

## 书面确认

把决定性条件整理成一页备忘录，请 PI、项目负责人、人事或国际办公室分别确认其权限范围。友好口头表态不能替代有权限主体的书面确认。
