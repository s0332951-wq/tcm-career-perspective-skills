# 08-model-evidence-matrix | 五个现有模型的高保真证据矩阵

整理日期：2026-07-11
规则：不新增模型。每个模型至少列两个相互独立场景，并明确人物事实到青年职业建议之间的推断跳跃。

## 模型一：临床价值是源头，也是回归点

| 场景 | 证据类型 | 本人直接表达 | 支持强度 |
|---|---|---|---|
| 2022署名文章：中医来自临床、服务需求；大方向落到具体科学问题 | 本人署名完整文章 | 是 | 强 |
| 2024新华访谈：新药研发以临床价值为导向 | 权威媒体直接采访 | 是 | 强 |
| 2020—2021抗疫叙述：临床特征、数据处理、证候与方药相连 | 本人长访谈/准一手整理 | 是/经编辑 | 中强 |

- 反例/失效条件：短期现场需求可能挤压基础研究；现场叙述不等于疗效因果证据。
- 职业迁移中的**模型推断**：优先保留稳定病种、病例反馈和问题定义权；张伯礼没有公开给出岗位评分公式。
- 升级后判断：**强，维持高权重**。

## 模型二：守住原创问题，用现代技术“以今释古”

| 场景 | 证据类型 | 本人直接表达 | 支持强度 |
|---|---|---|---|
| 2015新华长访谈：单体研究与理论指导复方研究并存；人才要保留辨证与实践 | 带时间戳完整文字实录 | 是 | 强 |
| 2021复旦长课：保留中医理念，并用现代科学解释其内涵 | 官方长篇演讲/问答全文 | 是 | 强 |
| 2026新华专访：以今释古、AI人主机制 | 权威媒体专访 | 是 | 强 |

- 反例/失效条件：“守正”边界可能含混并被用来回避证伪；现代指标也可能损失复杂临床信息。
- 职业迁移中的**模型推断**：AI、组学或海外方法只有补临床、证据、质量短板才加分。
- 升级后判断：**强，维持高权重**。

## 模型三：把传统经验送入可质询的证据体系

| 场景 | 证据类型 | 本人直接表达 | 支持强度 |
|---|---|---|---|
| 2021视频对谈整理：建立评价系统，看长期死亡率、发生率等结果 | 准一手视频访谈整理 | 是，经编辑 | 中强 |
| 2026新华专访：围绕临床需求形成高级别循证证据 | 权威媒体专访 | 是 | 强 |
| 2007—2026循证、试验和指南论文轨迹；CTS-AMI讨论链 | 多作者学术产出与同行质询 | 否，属参与轨迹 | 强但归因受限 |

- 反例/争议：Nature对疫情期证据等级的质疑；连花清瘟试验正式勘误；CTS-AMI存在来信、外推和机制问题讨论。
- 职业迁移中的**模型推断**：重视试验设计、统计、注册、报告和回应质疑；具体方法参数必须交给相应专家。
- 升级后判断：**强；直接表达和学术轨迹已形成双重支持**。

## 模型四：任务牵引，把单点成果沉淀成平台与转化闭环

| 场景 | 证据类型 | 本人直接表达 | 支持强度 |
|---|---|---|---|
| 2020人民网访谈：多省多院病例信息系统、组分库、重大需求、人才与评价机制 | 本人长访谈 | 是 | 强 |
| 2020教育部中心讲话：工程学院、数字生产线、产教中心、联盟、企业问题和学生训练 | 本人讲话全文整理 | 是，经整理 | 强 |
| 2021对谈与2022座谈：实践中给机会、搭平台；跨学科协同并让青年锻炼 | 准一手整理 | 是，经编辑 | 中强 |
| 2022署名文章：辨大势、做小题 | 本人署名完整文章 | 是 | 强 |

- 反例/失效条件：大任务可能把青年固化为执行者；公开资料无法还原预算、署名、数据、冲突和真实授权。
- 职业迁移中的**模型推断**：“四可”、五类沉淀、从独立模块到平台责任都是审计框架，不是本人晋升公式。
- 升级后判断：**平台原则与任务架构由中高升为强；内部组织机制仍为中等，不能提高到事实层**。

## 模型五：先练内功，再谈出海、规模和名气

| 场景 | 证据类型 | 本人直接表达 | 支持强度 |
|---|---|---|---|
| 2021复旦长课问答：先做好自身工作，有需求再分享，不强推并学习他者 | 官方长篇问答全文 | 是 | 强 |
| 2026公开访谈：基础研究、疗效证据、质量与供给构成现代化基础 | 权威媒体专访 | 是 | 强 |
| 2015长访谈：鼓励多样研究路线，不以单一路径取代中医理论问题 | 官方带时间戳实录 | 是 | 中强 |

- 反例/失效条件：过度准备会错失国际窗口；海外训练有时正是形成“内功”的条件。
- 人物立场判断：**高置信度**。仅指产品、标准和学术国际化应先补基础研究、疗效评价、质量与供给能力。
- 职业迁移中的**模型推断**：“补什么、临床怎么续、回国谁承接”三问并非本人原话；把国际化立场用于青年个人博后选择仅为**中等置信度的条件式推断**。
- 升级后判断：人物国际化立场维持强证据；个人海外选择迁移不得沿用高置信度，也不得单独决定去留。

## 权重结论

- 不删除、不新增模型。
- 模型一、二、五：核心证据达到至少两个独立一手场景。模型三由一份一手专访、一份准一手视频访谈整理及独立的多人论文/同行讨论轨迹共同支持；不得把准一手材料升格为完整一手。
- 模型四：平台原则达到强证据；“青年独立模块”和内部治理只能维持中等，必须在每个现实岗位另查。
- 表达DNA已有多份完整长文本，可由“中等”上调为“中高”；央视长视频无可靠字幕的缺口仍保留。
