# 05-decisions | 关键事件、选择与可迁移判断

整理日期：2026-07-11
原则：先列可核行动或本人表达，再列模型推断；不把结果倒推为万能决策公式。

## 案例一：给青年研究者的大方向与小问题

- 来源：[2022署名文章《处理好科学研究中的“大”与“小”》](https://institute.tjutcm.edu.cn/info/1109/1679.htm)
- **本人一手表达**：大方向看国家、健康需求与科技前沿；具体研究从可做深的小问题入手。即使不利于高层次论文，只要有利于健康需求，也可能值得做。
- **行动逻辑推断**：先选择长期值得解决的患者/公共问题，再切出个人能负责、可检验的模块。
- **职业迁移推断**：青年博士比较岗位时，应问能否拥有一个“做深做透”的问题单元，而不是仅看是否挂靠重大项目。
- **失效条件**：宏观需求可能被行政化或短期化；“小题”若没有数据、方法和反馈条件，也无法做深。

## 案例二：疫情现场到数据、实验与方案

- 来源：[人民网2020访谈](https://www.people.com.cn/n1/2020/0604/c32306-31735577.html)、[2021视频对谈整理](https://institute.tjutcm.edu.cn/info/1107/1193.htm)、[复旦2021长课](https://cifu.fudan.edu.cn/9e/06/c412a368134/page.htm)
- **本人一手/准一手表达**：从前线采集临床特征，经后方数据处理归纳证候，再调用组分库筛选并形成方药方案；另叙述一周内汇集多省多院病例信息。
- **机构/报道事实**：武汉现场存在医疗队、方舱、会诊和跨机构数据协作。
- **模型推断**：`患者问题 → 可检验临床证据 → 实验/数据协作 → 回到临床使用` 是可迁移的研究架构。
- **不可推断**：公开材料不能还原内部决策会议、失败候选、经费分配、各作者贡献或因果疗效。

## 案例三：长期推进组分中药与中成药二次开发

- 来源：[新华网2023](https://www.news.cn/health/20230720/9c39f8da8cd24d9a80798104f3b5a339/c.html)、[中国中医科学院人物页](https://www.cacms.ac.cn/nbe/detail/1399.html)、相关署名论文轨迹
- **本人一手表达**：组分中药、药材质量、二次开发与科学监管是现代化的重要部分。
- **机构事实**：官方页面记录长期研究方向、平台与相关成果。
- **模型推断**：单个研究可向质量、工艺、标准、监管和临床评价延展，形成复用平台。
- **失效条件**：产业合作可能偏向现有产品和短期交付；平台成果不能自动证明患者获益或青年独立性。

## 案例四：从学校生产线到产教融合平台

- 来源：[教育部中心2020讲话全文整理](https://www.csdp.edu.cn/article/6867.html)
- **本人一手表达**：回顾建立中医药工程学院、数字化生产线、产教融合中心及企业联盟，并把企业问题、学生训练和学校能力放在一起。
- **模型推断**：平台价值不只在设备，而在能否形成真实问题、学生实践、研究方法和外部使用的连接。
- **职业迁移推断**：博士面对大平台时，检查“可进入、可调用、可负责、可产出”，以及能否留下方法、数据/材料、标准、人才、协作网络。
- **证据边界**：“四可”和五类沉淀是本Skill审计工具，不是张伯礼术语；演讲中的产业数字未逐项独立审计。

## 案例五：人才主要在实践与平台中培养

- 来源：[2021视频对谈整理](https://institute.tjutcm.edu.cn/info/1107/1193.htm)、[2022科学家精神座谈会整理](https://institute.tjutcm.edu.cn/info/1109/1802.htm)、[教育部教书育人报道](https://edu.cctv.com/2022/05/09/ARTI1Wp2Fg4yML02hHk27K7X220509.shtml)
- **本人一手/准一手表达**：人才主要靠自身培养；在实践中给机会、搭平台，宽容失败；重视临床实践、问疑、合作与科学诚信。
- **权威二手**：学生与机构报道记录病例讨论、师承与院校教育结合等做法。
- **职业迁移推断**：评价岗位或导师时，除了论文，还要核验问题定义权、实践机会、反馈质量和贡献识别。
- **不可推断**：没有公开数据比较其学生与其他培养模式，也没有全部青年成员的授权和去向审计。

## 案例六：先做好本土能力，再开展国际交流

- 来源：[复旦2021长课问答](https://cifu.fudan.edu.cn/9e/06/c412a368134/page.htm)、[新华网2026访谈](https://www.news.cn/health/20260427/7d3d7bef2ee342ac94fda027c316382c/c.html)
- **本人一手表达**：先把自身工作做好，有外部需求再分享；尊重文明互鉴，也学习他者先进部分。现代化需加强临床证据、质量与科技解释。
- **模型推断**：国际化应建立在可交流的证据、质量、标准和本土承接上。
- **职业迁移推断**：海外博后只有补足明确方法短板并设计临床续接和回国承接时才加分。
- **失效条件**：国际经历本身也可能是形成方法能力的必要条件；产品国际化观点不等同本人对个体博后的直接建议。

## 职业链条证据审计

| 链条环节 | 证据性质 | 当前结论 |
|---|---|---|
| 患者问题 | 本人直接表达与临床行动 | 支持强 |
| 可检验的临床证据 | 本人直接表达、署名论文轨迹和公开争议 | 支持强 |
| 临床—科研—转化闭环 | 多个行动场景归纳 | 支持中高；“闭环”名称为模型推断 |
| 个人负责的独立模块 | 2022“小题深究”和给青年机会提供原则支持 | 支持中等；问题定义权、本人负责模块、数据访问、贡献署名、成果可带走范围和离组后使用权限仍需逐岗位核查 |
| 方法、数据、标准、人才、协作网络沉淀 | 多个平台与任务场景归纳 | 支持中高；五类清单是模型推断 |
| 平台与学科能力 | 机构事实与本人平台叙述 | 支持中高；因果归属及内部机制不明 |
